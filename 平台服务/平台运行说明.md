# ESG智能数据提取与分析平台运行说明

本目录提供“智析绿鉴—面向上市公司ESG报告的多模态指标抽取与可信分析系统”的动态服务端。平台使用 Flask 提供接口、Waitress 承载 HTTP 服务、SQLite WAL 保存报告元数据、任务状态、指标结果和证据片段。上传任务只调用统一算法入口；算法失败时任务进入 `failed`，不会使用关键词预览或浏览器模拟结果替代。

## 一、启动条件

1. Python 3.12；
2. 已安装 `算法源码/依赖环境清单.txt` 中的依赖；
3. 项目内存在 `正式数据产物/平台公开演示数据库.sqlite`；
4. 如需打开三年存量报告原文，配置 `ESG_REPORT_ROOT_SSE_ESG_2023_2025`；未配置时仍可查询元数据，但原文接口会明确返回文件未挂载。

模型 API 默认关闭。只有算法命令显式加入相应开关时才允许调用；当前平台在线任务不启用 DeepSeek 或 Claude。

网页上传任务依次进入任务执行器、统一算法入口和自动流水线。自动流水线默认启用高风险数值守卫，覆盖员工总数误取脚注或页码、案件数量误取报告年份、总量与强度口径混淆等通用回归场景；只有显式传入 `--skip-high-risk-numeric-guard` 才会跳过该步骤。

## 二、启动命令

```powershell
python 平台服务\平台接口.py
```

默认监听 `http://127.0.0.1:8000`。可通过环境变量修改主机、端口、运行目录、上传上限和任务超时，变量示例见项目根目录 `.env.example`。

首次启动会把只读种子库复制为 `平台运行数据/平台数据库.sqlite`。公开演示种子保留三年报告元数据，并包含按固定规则选择的5家企业、15份报告的P0演示结果，用于趋势与企业对比功能展示，不作为准确率评估样本。随后完成以下操作：

- 将运行库报告年份约束扩展为 2000—2100，不修改正式种子库；
- 创建指标目录、任务、结果、证据和审计事件表；
- 开启外键、WAL 和 30 秒锁等待；
- 载入 80 项指标定义；
- 将服务重启时仍为 `running` 的任务标记为 `interrupted`，不误判为成功。

## 三、核心接口

| 方法 | 地址 | 用途 |
|---|---|---|
| GET | `/api/v1/health` | 进程健康检查 |
| GET | `/api/v1/readiness` | 数据库、存储与任务执行器就绪检查 |
| GET | `/api/v1/summary` | 企业、报告、指标、任务和结果概览 |
| POST | `/api/v1/reports` | 上传 PDF 并创建真实抽取任务 |
| GET | `/api/v1/reports` | 查询报告 |
| GET | `/api/v1/reports/{report_version_id}/file` | 打开 PDF，支持 Range 请求 |
| GET | `/api/v1/jobs/{job_id}` | 查询排队、运行、成功、部分成功或失败状态 |
| GET | `/api/v1/results` | 查询结构化指标结果 |
| GET | `/api/v1/evidence/{evidence_id}` | 查询证据原文与 PDF 物理页 |
| GET | `/api/v1/trends` | 查询同企业、同指标、同标准单位的跨年趋势 |
| GET | `/api/v1/compare` | 查询用户选定企业的同年度同单位对比 |
| GET | `/api/v1/search` | 搜索企业、报告、指标和证据原文 |
| GET | `/api/v1/exports/results.csv` | 导出筛选后的结果 |

上传使用 `multipart/form-data`，字段为 `file`、`stock_code`、`company_name`、`report_year`、`report_title`，可选字段 `report_type` 支持 `ESG`、`SD`、`CSR`、`ENV` 和 `OTHER`。调用方可提供 `Idempotency-Key` 请求头；平台分别返回文件、报告版本和任务三个去重状态。

## 四、增量采集

`工具/ESG报告合规采集器.py`用于把人工确认的报告来源清单登记到同一真实任务队列。采集器默认只校验计划，不访问网络；只有显式传入`--执行`才下载。执行模式具有以下约束：

- 只允许HTTPS和命令行显式列出的来源域名及其子域；
- 拒绝本机、内网、链路本地和保留地址；
- 默认核验`robots.txt`，无法核验时停止；
- 支持超时、有限重试、请求间隔和最大文件大小；
- 校验PDF文件头，计算SHA-256并复用平台幂等机制；
- 只负责采集、登记和入队，不自行生成指标值或评分。

计划模式示例：

```powershell
python 平台服务\工具\ESG报告合规采集器.py `
  平台服务\工具\采集清单示例.csv `
  --允许域名 example.org
```

示例命令处于计划模式，不会产生网络请求。正式使用时应把示例地址替换为已核验来源，并在确认计划后增加`--执行`。独立运行采集器只创建排队任务；保持平台服务运行即可由后台任务执行器继续处理。

## 五、事实边界

- `succeeded` 只表示真实算法必需步骤完成且结果成功入库，不表示每个字段均正确；
- `auto_verified_high` 和 `auto_verified_medium` 是机器证据质量状态，不是人工金标准确率；
- `review_status` 默认始终为 `unreviewed`，只有真实人工审核记录才能修改；
- `no_candidate` 表示最终守卫链未保留候选，平台会清空残留值和单位；
- 趋势至少需要两个年份，且必须为定量指标和一致的标准化单位；
- 当前没有可靠行业分类数据，因此平台称“用户选定企业对比”，不称“同业比较”。
