# ESG指标抽取算法

本目录提供“智析绿鉴”统一算法入口、指标与规则配置、内部流水线模块及运行环境检查工具。算法面向上市公司ESG、可持续发展、社会责任和环境报告，输出字段级候选、单位、年度、证据页码、原文片段、风险标记、自动验收状态和披露评分。

## 目录

- `运行ESG指标抽取.py`：评委和用户使用的统一入口。
- `检查运行环境.py`：检查核心包、OCR包、配置和必需源码。
- `依赖环境清单.txt`：Python依赖。
- `配置`：80项指标体系、负样本库、定性披露规则和精度门控标记。
- `内部模块`：规则抽取、表格解析、OCR路由、证据守卫、自动验收和评分模块。
- `示例清单`：样本清单格式示例，不包含真实报告或个人路径。

## 安装

建议使用 Python 3.11 或 3.12，并在虚拟环境中执行：

```powershell
python -m pip install -r .\算法源码\依赖环境清单.txt
python .\算法源码\检查运行环境.py
```

`core_ready=true` 表示规则、表格和既有OCR缓存读取链可运行；`ocr_ready=true` 表示可对新增图片型页面执行OCR。DeepSeek和Claude均为条件模块，未配置密钥不会影响默认确定性流水线。

## 单份报告

规范文件名可自动识别股票代码、年度和报告类型：

```powershell
python .\算法源码\运行ESG指标抽取.py `
  --报告 "<ESG报告.pdf>" `
  --输出目录 ".\运行产物\本次分析" `
  --执行
```

若文件名不含公司元数据，请补充：

```powershell
python .\算法源码\运行ESG指标抽取.py `
  --报告 "<ESG报告.pdf>" `
  --股票代码 "600000" `
  --公司简称 "示例公司" `
  --报告年度 2025 `
  --报告类型 ESG `
  --执行
```

不传 `--执行` 时只校验输入并生成完整执行计划，不解析PDF。该安全默认值适合首次部署和参数检查。

## 批量报告

批量PDF应使用规范文件名，或按 `示例清单/示例样本清单.json` 提供独立样本清单：

```powershell
python .\算法源码\运行ESG指标抽取.py `
  --样本清单 ".\样本清单.json" `
  --输出目录 ".\运行产物\批量分析" `
  --执行
```

程序默认运行P0指标，可通过 `--优先级 P1`、`P2` 或 `all` 调整。OCR缓存目录可用 `--OCR缓存目录` 指定。

## 大模型条件模块

默认流程不调用外部大模型。确需启用DeepSeek时，应先通过环境变量提供密钥，再显式增加 `--启用DeepSeek --执行`。密钥不得写入源码、样本清单、日志或提交仓库。Claude视觉模块保留为复杂图片表格的预算受控兜底，不由统一入口默认开启。

## 输出与事实边界

每次运行会生成抽取结果、质量审计、执行计划、自动验收、披露评分和展示数据目录。字段槽位存在不代表报告已披露该指标；`candidate_found` 也不等同于人工金标正确。准确率、召回率和F1只能引用独立评估产物，不得由自动验收状态反推。

已完成的迁移回归证据见 `测试证据/算法迁移后五份回归验证.json`。该验证关闭大模型，5份样本共形成195个P0字段槽位、356行结果和271条候选，所有47个流水线步骤均通过。
